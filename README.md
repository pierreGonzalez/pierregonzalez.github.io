# Pierre Gonzalez — Online CV

Live: https://pierregonzalez.github.io

Single-page static CV (HTML + Bootstrap), deployed to GitHub Pages from `main`.

```powershell
npm install
npm run serve   # http://localhost:8080
npm run check   # HTML validation + link check
```

Working on this repo with an AI agent? Read [AGENTS.md](AGENTS.md) first.
Claims on the page are tracked in [docs/cv-facts.md](docs/cv-facts.md); improvement ideas live in [docs/CONTENT-SUGGESTIONS.md](docs/CONTENT-SUGGESTIONS.md).

Template base: "OnlineResume" (see `LICENSE-free.txt`).
