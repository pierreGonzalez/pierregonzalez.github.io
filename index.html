How I build with AI

AI speeds up the typing, not the thinking. My loop keeps a human accountable for every change:

  1. Spec first: a short written brief and an AGENTS.md that tells the agent the rules, commands and what it must never invent.
  2. Small steps: the agent plans, then works in small branches and pull requests.
  3. Automated gates: HTML validation and link checks run in CI on every change.
  4. Human review: I read and approve every diff; facts on this CV are tracked in a source-of-truth file.
